## Default prose policy

For every task producing or transforming natural-language prose, read and apply
writing-voice from the resolved local skill path configured for this environment.
Use the genre-appropriate profile and scale checking to task complexity. Preserve
meaning, evidence, author voice, data, quotations, code, and technical notation.
Do not make informal writing academic or brief answers unnecessarily long.

Before delegating prose tasks, ensure each worker can access the skill and
applicable project instructions. Include resolved paths and the reading requirement
in the task, or supply contents through the supported context mechanism.
Do not assume inheritance from the orchestrator. If access is unavailable, report
it; never claim a skill was read or applied without support.

Review final assembled prose for the same policy. Apply silently unless a material
issue requires disclosure. Do not disclose internal deliberation. This policy does
not authorize external writes, sends, or changes to research claims.
